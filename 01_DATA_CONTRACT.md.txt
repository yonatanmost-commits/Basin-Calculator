# Specification: Data Contract & State Management

## Core Philosophy
* Data interaction is handled strictly via a flat, spreadsheet-like JSON structure. 
* This schema is the single source of truth connecting any external frontend to the backend engine.
* Dimension inputs can accept strings with comma-separated values to support automatic averaging of field measurements.
* Supports a checkbox toggle (`uneven_slopes_enabled`) to switch between uniform and directional side slope inputs.
